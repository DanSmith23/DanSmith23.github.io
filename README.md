# Dan Smith — free static website

This is a standalone, responsive rebuild of danieljsmith.me designed for GitHub Pages, Cloudflare Pages or another static host.

## Before publishing

1. Open `index.html` and replace `daniel.james.smith@outlook.com` with the preferred contact email.
2. The profile image in `assets/dan-profile.jpg` was cropped from the supplied GoDaddy editor screenshot. Replace it with the original photo for best quality if available.
3. The current GoDaddy PDF is not bundled because the original asset is hosted by GoDaddy. The site instead includes a reconstructed web career journey. If you want the original PDF preserved, add it as `assets/career-journey.pdf` and link to it from `index.html`.

## GitHub Pages

Create a GitHub repository, upload all files/folders in this directory, then enable Pages from the repository's Settings. Add `danieljsmith.me` as the custom domain in Pages and follow GitHub's DNS instructions at GoDaddy.

Do not cancel GoDaddy Website Builder until the new site and domain have been tested successfully.
